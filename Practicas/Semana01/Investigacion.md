1. 🧠 Investigación previa

¿Qué es un HDD?Es un dispositivo de almacenamiento que funciona con un sistema de guardado magnetico 

¿Qué es un SSD? Es un dispositivo de almacenamiento que usa  microchips de memoria flash

¿Qué es un NVMe? El NVMe es un tipo de ssd que va conectado directo a la tajeta madre utilizando el puerto mas veloz disponible

¿Qué diferencia Existe entre un disco y una partición?

¿Qué es un sistema de archivos?El disco es el dispositivo fisico y la particion es una division del almacenamiento de ese disco fisico

¿Qué es NTFS?Es un sistema dearchivos que utiliza el sitema operativo windows para buscar, guardar y organizar dentro de un disco

¿Qué es ext4?Sistema de archivos que utiliza el sistema operativo Linux para buscar, organizar y guardar en un disco 

¿Qué es UEFI?Es un software moderno que viene en la tarjeta madre de la computadora y se encarga de encender, revisar componentes y darle control al sistema operativo

¿Qué es GPT?Es formato moderno que encarga de organizar la estructura de un disco para que la computadora sepa donde inicia y termina la particion

¿Qué es MBR?Es el formato antiguo que se encargaba de organizar la estructura de un disco y decirle a la computadora donde inicia y termina la particion

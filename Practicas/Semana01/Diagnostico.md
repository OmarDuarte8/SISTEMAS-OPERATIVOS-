2. ⌨️ Conocer el entorno



¿Qué es una terminal?Una interfaz de texto que permite interactuar con el sistema operativo mediante comandos

¿Qué es Bash?Interprete de comando en el sistema operativo Ubuntu

¿Qué significa ejecutar un comando?Darle una orden a la computadora mediante una palabra clave

¿Qué es la salida estándar?Un canal predeterminado donde se envian los datos enviados por los comandos

¿Qué significa utilizar sudo? Utilizar los permisos de administrador
